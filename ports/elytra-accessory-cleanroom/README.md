# Elytra Accessory 26.3 Compat

Clean-room compatibility implementation for Minecraft 26.3 + NeoForge.

This project does not copy or redistribute Elytra Accessory's original source code or production JAR.
It uses Ohmega's public API and NeoForge's GLIDING_FLIGHT attribute to let a vanilla Elytra work from Ohmega's built-in Special accessory slot.

Requires:
- Minecraft 26.3
- NeoForge 26.3.0.48-beta or newer compatible 26.3 build
- Ohmega 1.5.21 for Minecraft 26.3
